# 桌游小馆

六人面对面截码战的自制简化辅助网页。纯静态，无需安装、账号、数据库或后端。一部手机传看，双方线下面对面讨论；不支持多设备实时房间同步。

## 使用

通过 HTTPS 网站打开 index.html。双方各三人；每轮轮换出题者。同队先看四个秘密词，出题者独自看密码、填写三条线索，再隐藏秘密。第二轮起先锁定对手截码答案，再锁定队友答案，由出题者录入并揭晓。两队都完成当轮后判定胜负。

两次截码获胜或两次失误失败。最多八轮；同时触发或满八轮时比较截码减失误，同分记平局（简化规则）。不复制官方美术、卡牌或词库；词库为自制常见中文词。原游戏规则见 https://www.scorpionmasque.com/en/decrypto 。非官方产品。

## 隐私

游戏仅存本机 localStorage。无分析或跟踪。此模式要求信任玩家，不提供密码学防作弊；结束本局会清除保存。切换后台会隐藏秘密。

## GitHub Pages

推送至 main 后，在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions，仓库自带部署工作流。网页使用相对资源路径，兼容项目站点。
